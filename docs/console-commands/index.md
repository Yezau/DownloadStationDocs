## 使用说明

- 大多数游戏都只能在非铁人模式下使用控制台。
- 很多新世代引擎游戏需要先开启 `debug_mode`，再进入游戏调用控制台。
- 控制台默认可通过 `~` 打开；如果某作需要额外的 `debug_mode`，会在各自页面注明。
- 使用控制台会禁用成就。
