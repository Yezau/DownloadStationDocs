# 快速开始

本页是适用于大部分游戏、MOD 和补丁的通用安装流程。具体资源如有单独说明，以单独说明为准。

## 准备工作

- 安装最新的 **Visual C++ 运行库** 和 **DirectX**（下载站提供运行库合集与 DirectX Repair）。缺少它们是游戏打不开的头号原因，详见 [启动崩溃与缺少运行库](/troubleshooting/error-with-start-game)。
- 使用 [7-Zip](https://www.7-zip.org/) 或 [Bandizip](https://www.bandisoft.com/bandizip/) 解压，系统自带的解压功能处理大文件或分卷压缩包时容易出错。

## 安装步骤

### 1. 下载与解压

从本站下载压缩包后，解压到**不含中文、不含特殊符号**的路径，例如 `D:\Games\`。

::: tip 分卷压缩包
文件名形如 `xxx.part1.rar`、`xxx.part2.rar` 或 `xxx.7z.001`、`xxx.7z.002` 的是分卷压缩包。把所有分卷下载到同一个文件夹，只解压第一个即可。
:::

### 2. 备份原文件

覆盖任何游戏文件之前，**备份存档和即将被覆盖的原文件**。出现问题时，可以直接还原到原始状态。存档位置见 [文件位置速查](./file-locations)。

### 3. 对照目录结构覆盖文件

先观察补丁压缩包的目录结构，找到与游戏根目录**层级相同**的那一层，再整体复制过去，选择「替换目标中的文件」。

```txt
补丁压缩包\
└─ 某某补丁\         多出来的一层，不要复制它
   ├─ dlc\           从这一层开始复制
   └─ ...

游戏根目录\
├─ dlc\              与补丁中的 dlc 同级
├─ hoi4.exe
└─ ...
```

判断方法：补丁里的文件夹名（如 `dlc`）能在游戏根目录里找到同名文件夹，说明层级对了。

### 4. 验证

运行游戏，检查 MOD 或补丁是否生效。遇到问题先看 [按症状排查](/troubleshooting/)。
