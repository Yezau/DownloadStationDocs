# 关于汉化

目前除欧陆风云4 和其他较早的老游戏外，主流 P 社游戏本体都已提供官方简体中文。

## 本体切换中文

在启动器的设置中把语言改为 **简体中文**，重新开始游戏即可。

![启动器语言设置](https://img.alloy.eu.org/1751560231-ad148b84b4dd5e03-91b84f43-bda1-426b-ae53-fdddc9e0e0be.png)

## 欧陆风云4

欧陆风云4 没有官方中文，需要两样东西配合使用：

1. **双字节补丁**：让游戏能够显示中文字符，按补丁说明覆盖到游戏根目录。
2. **汉化 MOD**：提供中文文本，按 [安装 MOD](/troubleshooting/install-mod) 的方法安装并在启动器中启用。

::: warning
必须先打上双字节补丁，再启用汉化 MOD。只启用汉化 MOD 会显示乱码或方块。
:::

## MOD 的汉化问题

部分游戏早期没有中文，后来才加入官方中文。一些 MOD 的汉化是基于当时的英文本地化文件制作的，没有跟着切换到中文本地化文件，所以在中文界面下反而失效。

遇到这种情况，请按 MOD 说明的要求操作：有的 MOD 明确要求在启动器中**选择英文**启动，否则汉化不生效。
