# 入门指南

第一次在本站下载游戏、DLC 或 MOD，建议按顺序读完下面几页，大约五分钟。

| 页面 | 内容 |
| --- | --- |
| [快速开始](./quick-start) | 下载、解压、备份、覆盖文件的通用流程 |
| [启动游戏](./start-game) | 首次运行前安装 P 社启动器 |
| [关于汉化](./localization) | 切换中文，欧陆风云4 的双字节补丁，MOD 汉化 |
| [文件位置速查](./file-locations) | 存档、MOD、日志、启动器数据的位置 |

## 使用建议

1. 安装或覆盖任何文件之前，先备份存档和将被覆盖的原文件。
2. 游戏放在纯英文路径下，例如 `D:\Games\Hearts of Iron IV`，可以避开大部分路径问题。
3. 遇到报错，直接到 [按症状排查](/troubleshooting/) 找对应页面。
4. 想用作弊指令，查看 [控制台指令](/console-commands/)。
