# 启动游戏

P 社游戏需要通过 **P 社启动器（Paradox Launcher）** 启动，它负责加载 DLC 和 MOD。

## 第一次运行：安装启动器

每台电脑第一次运行 P 社游戏时，需要先安装启动器。

1. 解压游戏本体和 DLC 后，会得到类似下图的文件夹。双击 `launcher-installer-windows.msi`，按提示完成安装。

   ![启动器安装](https://img.alloy.eu.org/1751558919-9c3348ce5a6daf67-9a13fbd4-2eda-4170-bf21-e41145f5b71b.png)

2. 安装完成后，双击 `dowser.exe` 打开启动器，点击 **开始游戏**。

::: tip 已经装过启动器
这台电脑上已经安装过 P 社启动器（包括为其他 P 社游戏安装的），可以跳过第 1 步，直接运行 `dowser.exe`。
:::
