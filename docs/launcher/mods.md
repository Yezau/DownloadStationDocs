# MOD、订阅与播放集

主站的 MOD 在左侧栏的 **订阅** 页下载；**MOD** 页有两个视图：**播放集**（决定启用哪些 MOD、按什么顺序加载）和 **已安装**（本机全部 MOD）。

## 订阅与安装

![订阅页](/images/launcher/mod-browse.webp)

1. 打开左侧栏的「订阅」，按名称或创意工坊 ID 搜索。
2. 进入详情，点「订阅」：启动器记下订阅并安装，之后由它保持更新。只想要当前这一版就点「只安装这一版」。
3. 第一次安装会让你确认 MOD 存放位置，建议选系统盘以外的磁盘。

- 进度在详情页和下载页都能看到。
- 依赖 MOD 只做提醒，不会自动安装，可以按需勾选，或前往创意工坊订阅。
- 本地压缩包：在 MOD 页「已安装」里点「导入 ZIP」，或者直接拖进窗口。

### 订阅的 MOD 怎么更新

- 每次打开启动器时检查一次已订阅、已安装的 MOD。默认有新版就自动更新，也可以在 <MenuPath path="设置 / MOD / 订阅的 MOD 有更新时" /> 改成「只提醒」。
- 游戏或 P 社官方启动器正在运行时不会替换文件，这次的更新会跳过并提醒，关掉游戏后到 MOD 页更新即可。
- 订阅页右上角的「管理已订阅（N）」会打开「已安装」里只看已订阅的列表。每行的订阅开关可以单独开关，也可以多选后批量订阅或取消。
- 取消订阅不会删除文件。在「已安装」里删除 MOD 时，本机没有同一来源的其他副本就会一起取消订阅。
- Steam 工坊订阅的副本由 Steam 更新，手动导入的 ZIP 没法对照主站版本，这两类不能在这里订阅，表格里会写明原因。

## 播放集

![播放集](/images/launcher/mod-playsets.webp)

1. 选择一个播放集，或点「新建」。
2. 点「添加 MOD」挑选已安装的 MOD，用开关启用或停用，拖动调整加载顺序（越靠下越后加载）；也可以直接改左边的序号后回车。
3. 回到概览页点「开始游戏」，启动器会按选中的播放集写入游戏的 MOD 设置。

- 和 P 社官方启动器一样改了就存，没有「保存」按钮。改错了点「撤销上一步」，或按 <kbd>Ctrl</kbd> + <kbd>Z</kbd>。
- 第一次选择或新建播放集时，游戏原来的启用列表会先存成播放集「原启用列表」，随时可以切回去。
- 写入 MOD 设置时游戏和官方启动器需要关着，没关的话启动器会提示。之后单独打开官方启动器，它可能把 MOD 列表改回去；关掉它，从 YPGL 再开一次游戏就会按播放集写回。
- 不从 YPGL 启动游戏的话，可以在「⋯」菜单里选「现在应用到游戏」。「⋯」菜单还可以导出、导入 JSON，方便和朋友同步 MOD 列表。
- 从播放集移除 MOD 不会删除文件；在「已安装」里删除 MOD 无法撤销，正在使用的 MOD 删除后相关存档将无法读取。
- Steam 工坊订阅的 MOD 由 Steam 管理，启动器只读取、不删除。
- 城市：天际线系列的 MOD 请用 Skyve 管理，这两款游戏没有「订阅」页。
