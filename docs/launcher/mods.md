# MOD 与播放集

MOD 页有三个视图：**在线 MOD**（主站资源）、**已安装**（本机全部 MOD）、**播放集**（决定启用哪些 MOD、按什么顺序加载）。

## 安装 MOD

![在线 MOD](/images/launcher/mod-browse.webp)

1. 打开 MOD 页的「在线 MOD」，按名称或创意工坊 ID 搜索。
2. 进入详情，点击安装，进度在详情页和下载页都能看到。
3. 第一次安装会让你确认 MOD 存放位置，建议选系统盘以外的磁盘。

- 依赖 MOD 只做提醒，不会自动安装，可以按需勾选，或前往创意工坊订阅。
- 本地压缩包：在「已安装」里点「导入 ZIP」，或者直接拖进窗口。

## 播放集

![播放集](/images/launcher/mod-playsets.webp)

1. 选择一个播放集，或点「新建」。
2. 点「添加 MOD」挑选已安装的 MOD，用开关启用或停用，拖动调整加载顺序（越靠下越后加载）。
3. 点「应用到游戏」。

- 修改播放集前先关闭游戏和 P 社官方启动器。之后再打开官方启动器，它可能把 MOD 列表改回去，建议统一从 YPGL 启动。
- 「⋯」菜单可以导出、导入 JSON，方便和朋友同步 MOD 列表。
- 从播放集移除 MOD 不会删除文件；在「已安装」里删除 MOD 无法撤销，正在使用的 MOD 删除后相关存档将无法读取。
- Steam 订阅的 MOD 由 Steam 管理，启动器只读取、不删除。
- 城市：天际线系列的 MOD 请用 Skyve 管理。
