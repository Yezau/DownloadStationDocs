# MOD 与播放集

MOD 页分为三个视图：

| 视图 | 用途 |
| --- | --- |
| 播放集 | 决定这局启用哪些 MOD、按什么顺序加载，并写入游戏 |
| 已安装 | 本机的全部 MOD，可导入本地压缩包或删除 |
| 在线 MOD | 主站收录的 MOD，搜索、查看详情并一键安装 |

一句话流程：**在线 MOD 里安装 → 播放集里添加并排序 → 应用到游戏 → 概览页开始游戏**。

## 在线安装 MOD

![在线 MOD](/images/launcher/mod-browse.webp)

1. 进入游戏，打开 **MOD** 页，切换到 **在线 MOD**。
2. 按名称、简介或创意工坊 ID 搜索；也可以按下载量、订阅数、更新时间排序，或点击类型标签筛选（可多选，也可以排除某些标签）。
3. 点击卡片进入详情。详情里有创意工坊截图、中文介绍（标注为 AI 翻译）、工坊原文、文件大小，以及当前下载线路上的文件是否为最新。
4. 点击安装，MOD 会进入 [下载队列](./downloads-settings)，详情页顶部同步显示进度，也可以就地取消。

::: tip 第一次安装会询问存放位置
YPGL 把下载和导入的 MOD 统一放在一个「MOD 存放目录」里，游戏「文档」中的 `mod` 目录只放指向它的链接。第一次安装时会弹窗确认位置，默认位置在系统盘上，MOD 多了会占用大量空间，建议选择其他磁盘。之后可以在 <MenuPath path="设置 / 下载 / MOD 存放目录" /> 中更改，更改只影响之后安装或更新的 MOD。
:::

**依赖 MOD**：详情页下方会列出这个 MOD 的依赖。依赖仅作提醒，不会自动安装，可以按需勾选一起安装，或点击「前往工坊订阅」。

**下载不了的 MOD**：少数 MOD 只提供国内节点或站外链接，详情页会提示到主站页面下载。

## 播放集

![播放集](/images/launcher/mod-playsets.webp)

播放集是一份「这局要用哪些 MOD、按什么顺序加载」的清单。可以为不同玩法各建一个，例如「凯泽帝国单人」「原版联机」。

1. 切换到 **播放集**，在下拉框中选择一个播放集，或点击 **新建**。
2. 点击 **添加 MOD**，从已安装的 MOD 中挑选。
3. 用每行左侧的开关启用或停用，拖动左侧手柄调整加载顺序（也可以在「⋯」中输入位置或上移、下移）。越靠下的 MOD 越后加载，会覆盖前面 MOD 的同名内容。
4. 点击 **应用到游戏**，把启用列表写入游戏。显示「已应用到游戏」即完成。

右上角 **⋯** 菜单中还有：复制为新播放集、导入 / 导出 JSON（与朋友共享 MOD 列表）、从主站合集导入、安装主站上缺失的 MOD、读取当前游戏启用的 MOD、恢复上次应用前配置。

::: warning 修改播放集前请关闭游戏和官方启动器
游戏或 P 社官方启动器运行时无法应用播放集。之后如果再打开官方启动器，它可能会按自己的播放集把 MOD 列表改回去。建议统一从 YPGL 的概览页启动游戏。
:::

需要了解的规则：

- 空播放集会清空游戏的 MOD 启用列表，但保留 DLC 设置。
- 从播放集中移除 MOD 不会删除本地文件。
- 同一个创意工坊 MOD 同时有 Steam 订阅和本地下载两份时，只能启用其中一份。
- 概览页也能切换播放集，或者选择「不选播放集，不加载 MOD」直接玩原版。
- 播放集数据保存前会自动备份，误删或损坏时可以在 <MenuPath path="设置 / 播放集数据 / 查看数据备份" /> 中恢复。

## 已安装

列出本机这款游戏的全部 MOD，包括 Steam 创意工坊订阅的。

- **导入本地 MOD**：点击 **导入 ZIP** 选择压缩包，或者直接把 ZIP 拖进窗口。
- **删除 MOD**：会同时移除 `.mod` 配置和解压出来的文件，**无法撤销**。正在使用的 MOD 被删除后，相关存档将无法继续读取。
- Steam 订阅的 MOD 由 Steam 管理，YPGL 只读取、不删除，要移除请在 Steam 中取消订阅。

「状态」一列显示游戏当前的启用列表。要调整启用哪些 MOD 和加载顺序，请到播放集里修改后再应用。

## 不同游戏的差异

- **钢铁雄心4、欧陆风云4、群星** 等老引擎游戏：YPGL 写入的启用列表就是游戏实际加载的列表。
- **十字军之王3、维多利亚3、欧陆风云5、帝国：罗马**：启用状态同时受官方启动器的播放集影响，打开官方启动器后可能被改回，务必从 YPGL 启动。
- **城市：天际线、城市：天际线2**：MOD 结构与 P 社引擎不同，请分别使用 Skyve、Skyve CS-II 管理，YPGL 只处理补丁。
