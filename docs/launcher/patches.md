# 补丁

补丁页用来给当前游戏应用、切换或移除 DLC 补丁。两种补丁二选一，随时可以切换或移除，应用前会自动备份原始文件。

![补丁页](/images/launcher/patches.webp)

## 两种补丁

| 补丁 | 启动方式 | 适合 |
| --- | --- | --- |
| 正版补丁 | 「开始游戏」按 Steam 正版流程启动 | 单人游戏。已安装的 DLC 都能用，出新 DLC 也不用换补丁，断网可用 |
| 局域网补丁 | 由补丁自带的启动程序启动 | 和朋友联机，配合 [联机大厅](./multiplayer) 使用 |

::: info 补丁不含 DLC
补丁只让**已安装**的 DLC 生效，本身不包含 DLC 文件。缺的 DLC 请先在 [DLC](./dlc) 页补齐。
:::

## 应用补丁

1. 进入游戏，打开 **补丁** 页。
2. 点击要使用的补丁卡片（正版补丁或局域网补丁）。
3. 下方「将应用」显示对应的补丁包，点击 **应用**。本机没有缓存时会先自动下载。
4. 卡片上出现「已应用」，顶部「当前状态」随之更新，概览页的「出征前检查」也会显示对应补丁。

切换补丁时，选中另一张卡片再点应用即可，不需要先移除。

## 移除补丁

点击「当前状态」右侧的 **移除补丁**，YPGL 会从游戏目录移除补丁并恢复原始文件，之后游戏按原版流程启动。

卸载 YPGL 时也会询问「还原游戏补丁」还是「保留游戏补丁」，见 [常见问题](./faq#uninstall)。

## 补丁包

页面底部的「补丁包」列出可用的补丁及版本、大小、是否已在本机缓存：

- **已缓存** 的补丁可以离线应用。
- 点击刷新按钮重新获取补丁列表，点击「重新下载」更新本机缓存。
- 补丁列表获取失败且本机没有缓存时，可以到 QQ 群 538887146 获取补丁 ZIP，再点击 **导入 ZIP** 手动导入。

## 应用失败怎么办

- **先关闭游戏**。游戏运行时补丁文件被占用，应用或移除会失败。YPGL 会把本次改动回退到操作前，关掉游戏后重试即可。
- **安全软件拦截**。补丁会修改游戏目录中的文件，部分安全软件会拦截或删除。请确认 YPGL 是从主站下载的，再把 YPGL 和游戏目录加入安全软件的信任区，参见 [文档目录与权限问题](/troubleshooting/documents-folder#allow-write)。
- **提示当前游戏不支持局域网补丁**：这款游戏没有可用的局域网补丁，只能使用正版补丁。
- 游戏目录中的文件被其他程序改动过时，YPGL 不会强行覆盖，会停下来并保留恢复数据，请到群里反馈。
