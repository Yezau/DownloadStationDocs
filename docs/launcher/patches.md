# 补丁

![补丁页](/images/launcher/patches.webp)

| 补丁 | 说明 |
| --- | --- |
| 正版补丁 | 按 Steam 正版流程启动，已安装的 DLC 都能用 |
| 局域网补丁 | 由补丁自带的启动程序启动，配合 [联机大厅](./multiplayer) 使用 |

1. 进入游戏，打开补丁页，点选要用的补丁。
2. 点「应用」，本机没有缓存时会先自动下载。
3. 要切换时直接选另一种再应用；「移除补丁」会恢复游戏的原始文件。

- 补丁不含 DLC 文件，缺的 DLC 先在 [DLC 页](./library#dlc) 补齐。
- 应用失败：先关闭游戏再试；被安全软件拦截时，把 YPGL 和游戏目录加入信任区。
- 补丁列表获取失败时，可以用本机缓存的补丁，或者到群里获取补丁 ZIP 后点「导入 ZIP」。
