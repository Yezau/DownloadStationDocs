# 游戏库与 DLC

## 游戏库

![游戏库](/images/launcher/library.webp)

- **已安装**：点「进入」。
- **没识别出来**：点「添加目录」，选择游戏主程序所在的根目录（如 `hoi4.exe` 所在的文件夹）。
- **没安装**：点「下载」，选好版本和安装位置后加入下载队列，装完自动加入游戏库。
- 同一款游戏在本机有多个副本时会合并成一张卡片，用卡片上的版本下拉切换。
- 手动添加的游戏可以在「⋯」中移除，只移除条目，不删除游戏文件。

## DLC {#dlc}

![DLC 页](/images/launcher/dlc.webp)

1. 进入游戏，打开 DLC 页，确认上方的游戏目录正确。
2. 点「一键下载缺失」，下载完成后会自动装进游戏目录。

- 补丁只让已安装的 DLC 生效，本身不含 DLC 文件，缺的 DLC 要在这里下载。
- 「无法核对」多为壁纸、画册、原声带等赠品，不影响游戏。
- DLC 文件损坏时，用「更多下载选项」中的「全部重下」。
- 提示「没有在游戏目录里扫到任何 DLC 条目」，通常是游戏目录选错了。
- 个别 DLC 只提供站外链接，需要到主站页面下载。
