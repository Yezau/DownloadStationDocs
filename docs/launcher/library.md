# 游戏库与游戏本体

游戏库列出 YPGL 支持的所有游戏：本机已经装好的显示「已就绪」，没检测到的显示「未检测到」，可以直接下载或手动添加目录。

![游戏库](/images/launcher/library.webp)

## 认识游戏卡片

- 左上角标签表示来源：**Steam** 是 Steam 库中的游戏，**本地** 是手动添加或从本站下载的游戏。
- 右上角标签表示当前应用的补丁：正版补丁、局域网补丁，或者没有标签（未应用补丁）。
- 下方写着游戏版本号和补丁状态。
- 同一款游戏在本机有多个副本（例如 Steam 版和本地版）时，会合并成一张卡片，用卡片上的版本下拉切换。

右上角可以按 **全部 / 已安装 / 未安装** 筛选，或点击刷新按钮重新检测本机游戏。

## 已安装的游戏

点击 **进入**，打开这款游戏的概览页。之后可以在左侧栏「当前游戏」处随时切换。

游戏目录显示在概览页底部，点击右侧的铅笔图标可以修改。

## 已安装但没有被识别

从本站下载、解压到自定义位置的游戏，YPGL 不一定能自动找到：

1. 在游戏卡片上点击 **添加目录**。
2. 选择**游戏根目录**，即游戏主程序所在的文件夹，例如 `D:\Games\Hearts of Iron IV`（里面有 `hoi4.exe`）。
3. 添加成功后卡片变为「已就绪」。

::: warning 选对目录
不要选到上一层（如 `D:\Games`）或下一层的子文件夹。目录选错时，DLC 页会提示「没有在游戏目录里扫到任何 DLC 条目」。
:::

## 下载游戏本体

1. 在未安装的游戏卡片上点击 **下载**。
2. 选择要下载的 **版本**。
3. 选择 **安装位置**：
   - 默认装到与当前游戏并排的新文件夹，也可以直接填写一个还不存在的路径，加入队列前会自动创建并检查能否写入；
   - 也可以选择覆盖当前游戏目录。
4. 确认后进入 [下载队列](./downloads-settings)。下载完成会自动解压并加入游戏库。

下载对话框里的「下载缓存」是压缩包的临时存放位置，解压到游戏目录后会自动清理，请选择空间充足的磁盘。

下载一个新版本不需要先改动当前游戏的目录，原来的 DLC、补丁和启动位置保持不变。新旧版本都在游戏库里，用卡片上的版本下拉切换。

## 从游戏库移除

手动添加的游戏，可以在卡片的 **⋯** 菜单中选择「从游戏库移除」。这只是把条目从 YPGL 中移除，**不会删除游戏文件**，之后可以重新添加目录。
