# 下载与设置

## 下载队列

游戏本体、DLC、MOD 都排在同一个下载队列里。中断后可以断点续传，关闭窗口到托盘也不会打断下载；装完的 DLC、MOD 和游戏本体会自动刷新到对应页面。

![下载页](/images/launcher/downloads.webp)

- **进行中**：显示进度、速度和剩余时间，可以暂停、继续或取消。
- **已结束**：已完成、失败和已取消的任务。点击「清理已结束」清空这部分记录。
- **分卷压缩包**：同一组分卷会合并显示，暂停或取消会作用于整组，取消前会提示将删除多少已下载内容。点「查看每一卷」可以展开。
- **安装失败**：压缩包会保留，点「继续」只重新执行安装，不会重新下载。

### 下载线路

| 线路 | 特点 |
| --- | --- |
| 节点下载（默认） | 支持断点续传 |
| OneDrive | 不支持断点续传，中断后需要重新下载 |

在 <MenuPath path="设置 / 下载 / 默认下载线路" /> 中切换。某一项没有所选线路时会自动改走另一条，并在结果里说明。

## 设置 {#settings}

![设置页](/images/launcher/settings.webp)

所有设置立即生效。

| 分组 | 设置项 | 说明 |
| --- | --- | --- |
| 外观与窗口 | 主题 | 跟随系统、浅色、深色 |
| | 关闭按钮 | 每次询问、最小化到托盘、直接关闭。最小化到托盘时下载和联机会在后台继续 |
| 下载 | 下载缓存目录 | 压缩包先下载到这里，解压到游戏目录后自动清理。请选择空间充足的磁盘 |
| | MOD 存放目录 | 启动器下载、导入的 MOD 存放在这里，游戏「文档」里的 MOD 目录只放指向它的链接。所选文件夹里已有其他文件时，会在其中新建 `YPGL-MODs` 子文件夹 |
| | 默认下载线路 | 节点下载或 OneDrive |
| | 下载缓存 | 清理已取消任务的文件和已完成任务的断点残留，进行中的任务不受影响 |
| 启动器 | 检查更新 | 有新版本时点「下载并更新」，安装完成后自动重启，期间不要手动关闭 |
| EasyTier 联机组件 | 安装 / 更新 | 显示 Core、CLI 版本和网卡模式。从 GitHub 下载失败时填写「GitHub 加速地址」 |
| 播放集数据 | 查看数据备份 | 播放集保存前自动备份，文件损坏或误删时从这里恢复 |
| 关于 | 赞助支持 | 觉得有帮助，可以前往爱发电支持 |

::: tip 磁盘空间
游戏本体和大型 MOD 体积较大。下载缓存目录和 MOD 存放目录默认在系统盘，建议都改到空间充足的其他磁盘。
:::
