# 联机

![联机大厅](/images/launcher/network-join.webp)

**准备**：所有人都应用 [局域网补丁](./patches)，游戏版本和 MOD 列表保持一致。第一次使用时按提示安装 EasyTier 联机组件。

1. 房主在联机页点「连接」（房间号已自动生成），连接后点「分享房间」，把房间链接发给朋友。
2. 朋友在「加入房间」中粘贴链接，点「加入」。
3. 右侧显示「玩家已连接」后，回到概览页点「开始游戏」，在游戏的多人菜单里创建或加入。

![已连接的房间](/images/launcher/network.webp)

::: tip 游戏里找不到房间
钢铁雄心4、欧陆风云4、群星使用局域网补丁时，房间显示在多人列表的「互联网」一栏。
:::

## 连不上

| 现象 | 处理 |
| --- | --- |
| EasyTier 未安装 | 在 <MenuPath path="设置 / EasyTier 联机组件" /> 安装，下载失败时填写 GitHub 加速地址 |
| 需要管理员权限 | 以管理员身份运行 YPGL |
| 一直在连接服务器 | 默认服务器是测试用的海外服务器，换一种传输协议，或使用自建服务器 |
| 看不到对方 | 核对双方的房间号、服务器和补丁类型 |
| 开局后断开 | 核对游戏版本、MOD 和加载顺序 |

反馈问题时附上联机页右上角的「联机日志」。联机核心为 EasyTier，请勿用于违法用途。
