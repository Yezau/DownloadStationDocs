# 联机大厅

联机大厅内置 [EasyTier](https://github.com/EasyTier/EasyTier) 虚拟局域网：和朋友填同一个房间号，就像在同一个局域网里一样，可以直接在游戏里互相发现。

## 联机前准备

所有参与联机的人都需要：

1. 在 [补丁](./patches) 页应用**局域网补丁**。一起联机的人必须用同一种补丁。
2. 使用**相同的游戏版本**，启用**相同的 MOD**，加载顺序也一致（可以用播放集的「导出 JSON」发给朋友导入）。
3. 安装 **EasyTier 联机组件**。第一次打开联机页时会提示安装，也可以在 <MenuPath path="设置 / EasyTier 联机组件" /> 中安装。
4. 以管理员身份运行 YPGL（默认就是），否则无法创建虚拟网卡。

## 创建和加入房间

![联机大厅](/images/launcher/network-join.webp)

<div class="route">

1. **房主创建房间**：进入游戏，打开 **联机** 页
   - 「房间」里已经随机生成了一个房间号，点右侧的随机按钮可以重新生成
   - 点击 **连接**

2. **房主分享房间**：连接成功后点击 **分享房间**，复制房间链接（格式为 `房间号@服务器地址`）发给朋友

3. **朋友加入房间**：在「加入房间」中粘贴房间链接，点击 **加入**

4. **确认连接**：右侧「联机状态」显示「玩家已连接」，房间在线列表中能看到所有人和各自的延迟

5. **进入游戏**：回到概览页点击 **开始游戏**，在游戏的多人游戏菜单中，房主创建游戏，其他人加入

</div>

![已连接的联机房间](/images/launcher/network.webp)

::: tip 在游戏里找不到房间？
钢铁雄心4、欧陆风云4、群星等老引擎游戏，局域网补丁的房间显示在多人游戏列表的 **互联网** 一栏，点「刷新」后查看；不要只看「局域网」一栏。
:::

::: warning 房间号
好记的房间名容易被陌生人猜中，建议使用随机生成的房间号。
:::

## 设置项说明

| 设置 | 说明 |
| --- | --- |
| 服务器 | 默认服务器为测试用的海外服务器，可能不稳定。长期联机建议自建服务器：点「服务器」右侧的「自建服务器教程」，搭好后点下拉框旁的 **+** 添加 |
| 传输协议 | TCP / UDP / WS / WSS，连不上时可以换一种试试 |
| 设备显示名称 | 显示在玩家列表里的本机名称，仅支持英文字母、数字和 `-` `_` `.`，留空使用系统主机名 |
| 房间密码 | 自建服务器设置了密码时填写；使用默认服务器时留空 |
| 高级设置 | DHCP 自动分配 IP、手动 IPv4、强制中转、KCP / QUIC 代理。不清楚作用时保持默认 |

## 连不上怎么办

| 现象 | 处理 |
| --- | --- |
| 提示「EasyTier 未安装，联机不可用」 | 到 <MenuPath path="设置 / EasyTier 联机组件" /> 安装。从 GitHub 下载失败时，填写「GitHub 加速地址」后重试 |
| 提示「需要管理员权限，联机不可用」 | 关闭 YPGL，右键快捷方式选择「以管理员身份运行」 |
| 一直停在「连接服务器中」 | 默认服务器不稳定，换一种传输协议，或改用自建服务器 |
| 已连接但看不到对方 | 核对双方房间号和服务器是否完全一致；确认房间在线列表里有对方 |
| 列表里有对方，游戏里找不到房间 | 确认双方都应用了局域网补丁，并在多人列表的「互联网」一栏查找 |
| 能进房间但开局后断开或不同步 | 核对游戏版本、MOD 列表和加载顺序是否完全一致 |
| 虚拟网卡创建失败 | 安全软件可能拦截了 EasyTier，把它加入信任区；也可以在设置中查看「网卡模式」是否可用 |

排查时点击联机页右上角的 **联机日志**，把日志截图发到 QQ 群 538887146 可以更快定位问题。

::: danger 合法使用
联机核心为 EasyTier，请勿将其用于任何违法用途。
:::
