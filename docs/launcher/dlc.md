# DLC 补齐

DLC 页列出主站为这款游戏分发的全部 DLC，并对照游戏目录标出哪些已经安装、哪些还缺。下载的 DLC 会直接装进游戏目录。

![DLC 页](/images/launcher/dlc.webp)

::: info DLC 和补丁是两回事
补丁只让**已安装**的 DLC 生效，本身不包含 DLC 文件。缺的 DLC 要在这一页下载，或者到主站的 DLC 页面下载。
:::

## 一键补齐缺失 DLC

1. 进入游戏，打开 **DLC** 页。
2. 确认上方的游戏目录正确。
3. 点击 **一键下载缺失（N）**，缺少的 DLC 会全部加入 [下载队列](./downloads-settings)。
4. 下载完成后自动装进游戏目录，列表随之刷新为「已安装」。

切换到其他页面不会中断下载；遇到主站限流时会自动等待后重试。

## 列表分类

| 分类 | 含义 |
| --- | --- |
| 全部 | 主站上这款游戏的全部 DLC |
| 缺失 | 游戏目录中没有找到的 DLC |
| 已安装 | 游戏目录中已经存在的 DLC |
| 无法核对 | 多为壁纸、画册、原声带等游戏不加载的赠品，不计入缺失 |

单个 DLC 可以点卡片上的 **下载** 或 **重新下载**。

## 全部重新下载

DLC 文件损坏或不完整时，打开「更多下载选项」，选择 **全部重下**。所有 DLC 都会重新下载并覆盖已安装的版本，确认前会写明数量。只缺几个时，用「一键下载缺失」更快。

## 注意事项

- **DLC 只能装到游戏本体目录**，没有单独的安装位置选项。要换位置，请修改游戏目录本身。
- 少数 DLC 只提供国内节点或网盘等站外链接，YPGL 无法直接下载，会提示到主站页面下载。
- 默认下载线路在 [设置](./downloads-settings#settings) 中修改。某个 DLC 没有所选线路时会自动改走另一条，并在结果里说明。
- 如果提示「没有在游戏目录里扫到任何 DLC 条目」，通常是游戏目录选错了，先回到 [游戏库](./library) 检查目录，否则「全部缺失」的判断不可信。
