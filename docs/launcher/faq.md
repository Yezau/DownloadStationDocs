# 常见问题

## 安装与启动

### 打开 YPGL 后白屏，或提示缺少 WebView2

YPGL 的界面依赖 Microsoft Edge WebView2 运行时。Windows 11 自带；Windows 10 上安装程序会自动联网安装，网络不好时可能失败。

到微软官网的 [WebView2 下载页](https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/) 下载「常青版引导程序」（Evergreen Bootstrapper）安装，然后重新打开 YPGL。

### 每次打开都弹出用户账户控制提示

这是正常的。应用补丁、往游戏目录写文件都需要管理员权限，选择「是」即可。

### 被安全软件拦截或提示风险

补丁会修改游戏文件，联机组件会创建虚拟网卡，部分安全软件会因此拦截。请确认 YPGL 是从 [主站](https://share.yezau.com/launcher) 下载的，再把 YPGL 的安装目录和游戏目录加入安全软件的信任区。具体方法见 [文档目录与权限问题](/troubleshooting/documents-folder#allow-write)。

### 游戏库里没有我的游戏

从本站下载、解压到自定义位置的游戏需要手动添加：在游戏卡片上点「添加目录」，选择游戏主程序所在的根目录。见 [游戏库](./library#已安装但没有被识别)。

## 游戏与 MOD

### 进游戏后 MOD 没有加载，或被改回去了

1. 在概览页确认「出征前检查」的播放集一项显示「已应用到游戏」。没有应用时点「应用到游戏」。
2. 从 YPGL 的概览页启动，不要用 P 社官方启动器或游戏目录里的 `dowser.exe` 启动。官方启动器会按自己的播放集重写 MOD 列表。
3. 修改播放集前先关闭游戏和官方启动器。

### DLC 显示缺失，但我确定已经装了

先检查游戏目录是否选对（必须是游戏根目录）。目录正确时，个别 DLC 的文件夹名与主站记录不一致，会显示为「无法核对」，这类 DLC 不影响游戏使用。

### 应用补丁失败

关闭游戏后重试。仍然失败时检查安全软件是否拦截了游戏目录，见 [补丁 · 应用失败怎么办](./patches#应用失败怎么办)。

### 联机找不到房间

见 [联机大厅 · 连不上怎么办](./multiplayer#连不上怎么办)。最常见的原因是双方补丁类型不同，或者老引擎游戏没有在多人列表的「互联网」一栏查找。

## 下载

### 下载很慢或经常中断

- 在 <MenuPath path="设置 / 下载 / 默认下载线路" /> 中换一条线路试试。
- 尽量使用「节点下载」，OneDrive 线路不支持断点续传。
- 中断的任务在下载页点「继续」即可，不需要重新开始。

### 系统盘空间不够

在设置中把「下载缓存目录」和「MOD 存放目录」改到其他磁盘。已完成任务的残留文件可以用「清空缓存」清理。

## 更新与卸载 {#uninstall}

### 怎么更新 YPGL

YPGL 会自动从主站检查更新。也可以在 <MenuPath path="设置 / 启动器 / 检查更新" /> 手动检查，点「下载并更新」后会自动安装并重启。自动更新失败时，到 [主站](https://share.yezau.com/launcher) 下载最新安装包覆盖安装。

### 卸载 YPGL 会影响游戏吗

在 Windows 的 <MenuPath path="设置 / 应用 / 已安装的应用" /> 中卸载 YPGL 时，会先让你选择：

- **还原游戏补丁**：把游戏目录恢复为原始文件。
- **保留游戏补丁**：游戏目录中的补丁保持现状。

另外还有一个独立的「删除应用数据」选项：勾选后会删除配置、日志、缓存、补丁备份；不勾选则保留，之后重装 YPGL 还能继续使用。**删除补丁备份后，就无法再用这些备份还原游戏。** 下载的文件和 MOD 按卸载程序中各自的选项处理。
