# 常见问题

### 打开后白屏，或提示缺少 WebView2

到微软 [WebView2 下载页](https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/) 安装「常青版引导程序」，然后重新打开 YPGL。

### 每次打开都弹出管理员权限提示

正常现象，写入游戏目录需要管理员权限。

### 被安全软件拦截

确认是从 [主站](https://share.yezau.com/launcher) 下载的，再把 YPGL 安装目录和游戏目录加入信任区，参见 [文档目录与权限问题](/troubleshooting/documents-folder#allow-write)。

### MOD 没加载，或被改回去了

在概览页确认播放集显示「已应用到游戏」，并且从 YPGL 启动，不要用 P 社官方启动器或 `dowser.exe` 启动。

### 下载慢或中断

在 <MenuPath path="设置 / 下载 / 默认下载线路" /> 换一条线路。OneDrive 线路不支持断点续传，中断的任务在下载页点「继续」即可。

### 系统盘空间不够

在设置里把「下载缓存目录」和「MOD 存放目录」改到其他磁盘。

### 卸载会影响游戏吗

卸载时可以选择「还原游戏补丁」或「保留游戏补丁」。勾选「删除应用数据」会同时删除补丁备份，之后无法再用备份还原游戏。
