# 常见问题

### 打开后白屏，或提示缺少 WebView2

到微软 [WebView2 下载页](https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/) 安装「常青版引导程序」，然后重新打开 YPGL。

### 每次打开都弹出管理员权限提示

正常现象，写入游戏目录需要管理员权限。

### 被安全软件拦截

确认是从 [主站](https://share.yezau.com/launcher) 下载的，再把 YPGL 安装目录和游戏目录加入信任区，参见 [文档目录与权限问题](/troubleshooting/documents-folder#allow-write)。

### MOD 没加载，或被改回去了

在概览页的「出征前检查」看播放集一行：显示「已应用到游戏」或「启动时写入启用列表」都可以。然后从 YPGL 点「开始游戏」，不要用 P 社官方启动器或 `dowser.exe` 启动；启动器会在开游戏前按选中的播放集写入 MOD 设置。

### 点「开始游戏」后提示「应用程序控制策略已阻止此文件」（os error 4551）

这是 Windows 的应用控制拦下了启动程序，不是文件损坏，重装游戏或重新打补丁一般没用。

1. 打开「Windows 安全中心 → 应用和浏览器控制 → 智能应用控制」查看状态。确认是它拦截的，可以自行选择关闭，但会降低整台电脑的防护，关闭前看清该页的提示。
2. 公司或学校管理的电脑，请联系管理员检查应用控制策略和被拦截的文件。
3. 处理后回到 YPGL 再点一次「开始游戏」。

### 下载慢或中断

在 <MenuPath path="设置 / 下载 / 默认下载线路" /> 换一条线路。OneDrive 线路不支持断点续传，中断的任务在下载页点「继续」即可。

### 系统盘空间不够

在设置里把「下载缓存目录」和「MOD 存放目录」改到其他磁盘。

### 卸载会影响游戏吗

卸载时可以选择「还原游戏补丁」或「保留游戏补丁」。勾选「删除应用数据」会同时删除补丁备份，之后无法再用备份还原游戏。
