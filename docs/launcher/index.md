# YPGL 启动器

YPGL（Yezau Paradox Game Launcher）是业钊下载站的桌面启动器。下载游戏本体、补齐 DLC、安装 MOD、切换补丁、和朋友联机，都在一个窗口里完成，不用再手动找目录、挪文件。

![YPGL 概览页](/images/launcher/home.webp)

## 能做什么

| 功能 | 位置 | 说明 |
| --- | --- | --- |
| 游戏本体 | [游戏库](./library) | 自动识别本机装好的 P 社游戏，没装的可以直接下载本体 |
| DLC 一键补齐 | [DLC](./dlc) | 对照游戏目录列出缺少的 DLC，一键下载并装进游戏目录 |
| MOD 与播放集 | [MOD](./mods) | 搜索站内 MOD 并安装；播放集决定启用哪些 MOD、按什么顺序加载 |
| 正版 / 局域网补丁 | [补丁](./patches) | 两种补丁二选一，一键应用，随时还原 |
| 联机大厅 | [联机](./multiplayer) | 内置 EasyTier 虚拟局域网，和朋友填同一个房间号就能一起玩 |
| 下载队列 | [下载](./downloads-settings) | 游戏、DLC、MOD 共用一个队列，断点续传，关窗到托盘也不中断 |

支持的游戏：钢铁雄心4、十字军之王3、欧陆风云4、欧陆风云5、群星、维多利亚3、帝国：罗马、城市：天际线、城市：天际线2，其他游戏可以手动添加目录。城市：天际线系列的 MOD 请使用 Skyve 管理，YPGL 只负责它们的补丁。

## 运行要求

- Windows 10 / 11，64 位。
- WebView2 运行时。Windows 11 自带；Windows 10 缺少时，安装程序会自动联网安装。
- 管理员权限。应用补丁、往游戏目录里写文件都需要它，所以每次打开 YPGL 都会弹出用户账户控制（UAC）提示。

## 下载与安装

1. 打开主站的 [YPGL 启动器页面](https://share.yezau.com/launcher)，点击 **下载启动器**。下载慢或失败时，换用页面上的备用线路。
2. 运行下载到的 `YPGL_版本号_x64-setup.exe`，按提示完成安装。
3. 从开始菜单或桌面快捷方式打开 YPGL，用户账户控制提示「是否允许此应用对你的设备进行更改」时选择 **是**。
4. 之后 YPGL 会自动从主站检查更新，也可以在 <MenuPath path="设置 / 启动器 / 检查更新" /> 中手动检查，点击「下载并更新」后会自动安装并重启。

## 界面一览

左侧栏从上到下：

| 区域 | 内容 |
| --- | --- |
| 搜索游戏或页面 | 按 <kbd>Ctrl</kbd> + <kbd>K</kbd> 打开，可直接跳到任意一款游戏、任意一页 |
| 游戏库 | 所有支持的游戏，已装的进入，没装的下载或添加目录 |
| 当前游戏 | 点击可切换游戏；下面是这款游戏的 **概览、MOD、DLC、补丁、联机** 五页 |
| 工具 | **下载** 队列和 **设置** |

## 四步上手

<div class="route">

1. **选游戏**：在 [游戏库](./library) 进入要玩的游戏
   - 已装但没认出来，点「添加目录」选择游戏根目录
   - 没装，点「下载」获取游戏本体

2. **补内容**
   - [DLC](./dlc) 页点「一键下载缺失」补齐 DLC
   - [MOD](./mods) 页安装 MOD，在播放集里选好要启用的 MOD 并「应用到游戏」

3. **打补丁**：在 [补丁](./patches) 页选择正版补丁或局域网补丁并应用

4. **开始游戏**
   - 要联机，先到 [联机](./multiplayer) 页和朋友进同一个房间
   - 回到概览页，确认「出征前检查」没有问题，点击 **开始游戏**

</div>

## 概览页与出征前检查

进入一款游戏后，第一页是概览。上半部分是 **开始游戏** 按钮，旁边写明这次会怎样启动、会带哪些 MOD；下半部分的「出征前检查」逐项列出：

| 检查项 | 看什么 |
| --- | --- |
| 补丁 | 当前应用的是哪种补丁，决定游戏怎样启动 |
| DLC | 已装多少、缺多少，缺的可以直接点「下载缺失的」 |
| 播放集 | 这局会载入哪个播放集，能在这里直接切换，或选择「不选播放集，不加载 MOD」 |
| 联机 | 是否已进入联机房间、房间里有几名玩家 |

::: tip 不经过官方启动器
从 YPGL 点击「开始游戏」会直接启动游戏（应用局域网补丁时由补丁自带的启动程序启动），**不经过 P 社官方启动器**。官方启动器的白屏、数据库错误等问题不会影响这里的启动，官方启动器也不会把 YPGL 写好的 MOD 列表改掉。
:::

启动前如果发现会失败的情况，例如播放集还没写入游戏、补丁正在写入，按钮会被拦下，原因和处理入口直接显示在按钮旁边，点一下就能处理。
