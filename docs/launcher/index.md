# YPGL 启动器

本站的桌面启动器：下载游戏本体、补齐 DLC、安装 MOD、切换补丁、联机，都在一个窗口里完成。

![YPGL 概览页](/images/launcher/home.webp)

## 安装

- 系统：Windows 10 / 11 64 位，需要 WebView2（Windows 11 自带，Windows 10 缺少时安装程序会自动安装）。
- 到 [主站启动器页面](https://share.yezau.com/launcher) 下载安装包，按提示安装。
- 每次打开都会请求管理员权限（写入游戏目录需要），选「是」。
- 启动器会自动检查更新，也可以在 <MenuPath path="设置 / 启动器 / 检查更新" /> 手动更新。

## 三步上手

1. **选游戏，补内容**：在 [游戏库](./library) 进入游戏，没认出来就「添加目录」；再到 [DLC](./library#dlc) 和 [MOD](./mods) 页补齐内容。
2. **打补丁**：在 [补丁](./patches) 页选择正版补丁或局域网补丁。
3. **开始游戏**：要联机先到 [联机](./multiplayer) 页和朋友进同一个房间，然后在概览页点「开始游戏」。

## 概览页

「开始游戏」会直接启动游戏，**不经过 P 社官方启动器**（局域网补丁由补丁自带的启动程序启动）。下方「出征前检查」列出补丁、DLC、播放集、联机四项状态，有问题时旁边会给出处理按钮。

左侧栏依次是游戏库、当前游戏的五个页面（概览、MOD、DLC、补丁、联机）、下载和设置。按 <kbd>Ctrl</kbd> + <kbd>K</kbd> 可以快速跳到任意游戏或页面。

支持的游戏：钢铁雄心4、十字军之王3、欧陆风云4、欧陆风云5、群星、维多利亚3、帝国：罗马、城市：天际线、城市：天际线2。
